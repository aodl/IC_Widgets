This is a partial discovery sample from two observation windows. The Registry files contain the affected subnet records. Node registrations, assignments elsewhere in the Registry and full review evidence were outside the capture. The sample does not establish a complete search for cross-proposal interactions or a deploy-time outcome. The recorded bytes are development evidence and are outside the deployed catalogue.
